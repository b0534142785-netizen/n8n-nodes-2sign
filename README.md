# n8n-nodes-2sign

נוד ל-n8n לשירות **חתימה ירוקה** (2Sign): שליחת מסמכים לחתימה דיגיטלית, סבבי חתימות עם כמה חותמים, קבלת המסמך החתום, והתחלת תהליך כשמסמך נחתם.

הנוד נבנה לפי התיעוד הרשמי: https://2sign-co-il.gitbook.io/2sign.co.il-docs

## התקנה

ב-n8n: הגדרות (Settings) ← Community nodes ← Install, וכותבים `n8n-nodes-2sign`.

אי אפשר להתקין את הנוד ב-n8n Cloud, כי הוא לא מאושר על ידי n8n. הוא כתוב בעברית, ולכן הוא לא עומד בכללי האישור שלהם.

## החיבור

1. פותחים חשבון בחתימה ירוקה, ומבקשים גישה ל-API: תמיכה ← API access.
2. אחרי האישור: הגדרות ← API. מעתיקים את ה-Client ID.
3. לוחצים Generate ליד Client Secret, ו**מעתיקים את הסוד לפני שלוחצים Save**. אחרי השמירה אי אפשר לראות אותו שוב.
4. ב-n8n יוצרים חיבור "חתימה ירוקה (2Sign) API", ומדביקים את המזהה ואת הסוד.

אפשר להתחבר גם במייל ובסיסמה, לבדיקות. גם אז צריך את המזהה, כדי לקרוא תבניות.

## מה הנוד עושה

**משימה לחתימה (חותם אחד)**
- יצירה מתבנית: מספר תבנית אחד, או כמה מספרים עם פסיק שמתחברים למסמך אחד.
- יצירה מקובץ: הקובץ מגיע מהנוד הקודם, עולה לחתימה ירוקה ונשלח.
- הנמען יכול להיות לקוח שמור, נמען חד-פעמי (טלפון או מייל) או קבוצה.
- שליחה במייל, ב-SMS או בוואטסאפ, או בלי שליחה. אז מקבלים קישור לחתימה ושולחים אותו בעצמכם.
- קבלת פרטים, חיפוש משימות, שליחה מחדש, קישור לחתימה ומחיקה.

**סבב חתימות (כמה חותמים)**
- יצירה מתבנית או מקובץ. החותמים חותמים אחד אחרי השני או כולם ביחד.
- החותמים מגיעים מקבוצה שמורה, או מרשימה בנוד: לקוח שמור, או שם עם טלפון או מייל.
- מקום החתימה נקבע לפי השדות שבתבנית, לפי סימן נדיר שכתוב בקובץ לכל חותם (למשל `###`), או לפי מיקום מדויק.
- קבלת פרטים, והסרה של חותם אחד מהסבב.

**מסמכים וקבצים של משימה**
- המסמך החתום, המסמך המקורי, צילום תעודת הזהות, הקבצים שהחותם העלה, קובץ האקסל המסכם, או הכול ביחד.
- אפשר לקבל את הקובץ עצמו, או קישור זמני להורדה.

**לקוח:** יצירה, קבלה לפי מספר, חיפוש לפי שם, מייל או טלפון, ומחיקה.

**קבוצת לקוחות:** יצירה, הוספת לקוחות, קבלה לפי מספר, וכל הקבוצות.

**תבנית:** קבלה לפי מספר (כולל מיקומי השדות), וחיפוש.

**החשבון:** כמה משימות נוצרו החודש.

**אפשרויות נוספות ביצירת משימה או סבב:**
- אבטחה: קוד חד-פעמי לטלפון, קוד סודי, צילום תעודת זהות, תאריך הנפקה, סרטון, ומסמכים נוספים מהחותם.
- מילוי מראש של שדות, שדות לפי סימנים בקובץ, וחתימה במקום קבוע בעמוד.
- חותמת של החשבון, נושא ותוכן למייל, ושפה.
- מידע שלכם (למשל מספר לקוח במערכת שלכם) שחוזר בהודעה האוטומטית אחרי החתימה.

## הנוד "חתימה ירוקה - כשמשהו קורה"

התהליך מתחיל כשחתימה ירוקה שולחת הודעה אוטומטית, למשל כשמסמך נחתם.

1. מוסיפים את הנוד ומעתיקים את הכתובת שלו (Production URL).
2. בחתימה ירוקה: מנוי ← הגדרות ← הגדרות חשבון ← הגדרות מתקדמות ← הגדרות API נוספות. מדביקים את הכתובת ושומרים. אפשר להגדיר כתובת נפרדת לכל תבנית.
3. מפעילים את התהליך ב-n8n.

הנוד מפענח בעצמו את רשימת השדות שחוזרת מוצפנת (signaturePositions), ומוסיף קישור לחתימה. אפשר גם להוסיף מפתח סודי לכתובת (`?key=...`), כדי שהודעות מזויפות לא יפעילו את התהליך.

## מה נבדק מול השרת האמיתי (24.11.2026)

נבדק מול חשבון אמיתי, רק בקריאה: בלי ליצור משימות ובלי לשלוח מסמכים.

- **התחברות:** עובדת. מפתח הגישה חוזר בתוך `ResponseObject`.
- **סוד שגוי:** השירות עונה בקוד 200 עם `Status: "failure"`. הנוד ובדיקת החיבור מזהים את זה ועוצרים.
- **רשימה בלי תוצאות:** כשאין קבוצות או לקוחות, השירות עונה `failed` עם קוד 19. הנוד מחזיר רשימה ריקה ולא שגיאה.
- **חיפוש משימות:** בלי שום סינון השרת קורס. לכן הנוד תמיד שולח את המזהה (Token).
- **חיפוש לקוחות:** בלי שום שדה השרת קורס. לכן הנוד מבקש למלא לפחות שדה אחד.
- **מסמכים:** המסמך המקורי והחתום חוזרים כ-PDF, כקובץ וגם כקישור.
- **מצב משימה:** 20 = נחתם.
- **התשובות:** הנוד מחזיר רק את התוכן (`ResponseObject`), בלי השדות הריקים.
- **העלאת קובץ:** עובדת. הנוד בונה את גוף הבקשה בעצמו, בלי FormData ו-Blob, כי הם לא קיימים בכל סביבה של n8n. העלאה לבד לא נספרת במכסה.
- **יצירה מקובץ:** הכתובת שבתיעוד (`TasksNew/CreateTask`) לא קיימת אצלם. הנוד משתמש ב-`Tasks/CreateTask`, שעובדת גם לתבנית וגם לקובץ.
- **מחיקת משימה:** עובדת.
